# Been Android UI-U1 实施与验收检查点

日期：2026-10-29
状态：`ACCEPTED`
前置：UI-U0 已由所有者明确验收

所有者决定：所有者于 2026-10-29 明确确认“UI-U1 验收通过”。

## 1. 本阶段边界

本检查点只处理可读性、字号回流、编辑页底部安全区和地图署名安全区，不改变已验收的“动态柔糖”“夜雾”、城市地图背景、四目的地、旅程带、收藏长按或现有业务流程。地图坐标与轨迹线的投影、聚类和缩放稳定性未改动，仍属于 UI-U2。

## 2. 已实施内容

- 透明根 Scaffold 明确继承 `onSurface`，修复深色地图背景上标题、清单分组和个人页标题变黑的问题。
- 轨迹添加／编辑页顶栏只保留页面标题；删除重复记录方式、日期时间和精度的伪副标题。精度继续保留在轨迹卡片，并作为坐标组的紧邻元信息显示；定位失败才显示必要反馈。
- 编辑页底部主操作使用透明承载区，不再绘制 tonal-elevation `Surface`；仍同时应用导航栏和 IME 安全区，滚动内容按实际底栏高度让位。
- 系统状态栏与导航栏启用透明 edge-to-edge，关闭 Android 强制导航栏对比 scrim；页面背景延伸至手势区，手势条按浅／深主题自动反色。
- 轨迹地点名保持单行：失焦时尾部省略，聚焦时恢复完整文本并水平滚动；不因长名称改变卡片高度。
- 轨迹元信息固定单行省略，并使用不换行的数值／单位组合，避免 2.0× 出现孤立的 `m`。
- MapLibre 内建 logo／署名关闭，只保留一份自定义合法署名；署名使用半透明表面、语义内容色和 `safeDrawing` 底部／水平 inset。
- debuggable APK 支持一次性的 ADB intent extra `com.bugchecking.app.extra.FORCE_STATIC_THEME=true`，仅用于真机强制静态回退配色；release 构建不响应，也不新增产品设置或持久化偏好。
- 智能导入的初始输入区可滚动，并在滚动内容末尾预留 IME 高度；共享空白点击清焦点只在未消费的抬手事件触发，避免 2.0× 滚动时误收键盘。

目视结论：固定矩阵中没有不可读标题、硬裁切、底部操作被系统导航／键盘遮挡或重复地图署名。2.0× 地图署名重排为三行，面积增大但内容完整且避开三键导航区。地图坐标和轨迹线在缩放中的漂移仍可复现，按计划保留给 UI-U2，未误记为本阶段通过项。

后续修正：轨迹添加／编辑页的重复状态副标题已删除，精度已移回坐标组附近；最终代码的自动门禁通过并已保留数据安装。解锁后已在手势导航下完成修正版真机复核：动态浅色 1.0×／2.0× 覆盖添加页与设备轨迹编辑页，动态深色 1.0× 覆盖两页顶栏并在设备轨迹编辑页确认坐标后精度。两页顶栏均只保留页面标题，日期／时间没有重复，精度与坐标相邻，底部主操作避开手势区。深色添加页当次定位仍在进行，因此其精度呈现由同一组件路径下的设备轨迹编辑页，以及浅色添加页 1.0×／2.0× 共同覆盖。
